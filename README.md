## 🚀 使用方式

### 方式一：直接打开

双击 `index.html` 文件即可在浏览器中打开学习网站。

### 方式二：本地服务器

```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx serve
```

然后在浏览器访问 `http://localhost:8080`

## ✨ 特性

- 📱 **全端适配**：完美支持手机、平板、电脑访问
- 🔓 **无需登录**：打开即用，无复杂校验
- 🎨 **现代设计**：深色主题，舒适的学习体验
- ⚡ **纯静态**：无需后端，部署简单
- 📝 **默写速记**：交互式学习卡片，高效记忆知识点
